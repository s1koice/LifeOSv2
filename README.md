# NEXUS OS

Тёмная персональная система планирования жизни: dashboard, задачи, цепочка целей, проекты, привычки, финансы, здоровье, недельное планирование, журнал и AI-ассистент.

## Что уже работает

- адаптивный интерфейс для телефона, планшета и компьютера;
- iOS-подобный интерфейс: системная типографика, стеклянные панели, крупные зоны нажатия, нижняя мобильная навигация и формы-шторки;
- демо-данные и работа без регистрации или базы данных;
- локальное сохранение задач, привычек, финансов, планов и журналов в `localStorage`;
- создание, удаление и обновление задач, целей, проектов, операций и событий;
- полноценный рабочий процесс PARA: входящие, проекты, сферы, ресурсы и архив;
- быстрый разбор входящей записи в задачу или ресурс без повторного ввода;
- голосовой быстрый ввод во «Входящие» через распознавание речи браузера (если оно поддерживается устройством);
- еженедельный обзор с сигналами о неразобранных записях, проектах без следующей задачи и просроченных действиях;
- редактируемые стандарты и самооценка сфер жизни;
- контрольные этапы и собственная база материалов внутри каждого проекта;
- финансовый учёт в израильских шекелях (ILS / ₪);
- отдельные счета для наличных, банка и кредитной карты, переводы и редактирование остатков;
- кредитные покупки с 1–12 платежами и автоматическим графиком списаний 15-го числа;
- месячный бюджет по категориям с живым сравнением плана и факта;
- недельная шкала расходов из наличных, банковской и кредитной карт с линией допустимого темпа;
- постоянные расходы с выбранным счётом и датой, которые автоматически создаются один раз в месяц;
- денежный календарь на любой месяц с постоянными списаниями, кредитными платежами, суммами и статусом оплаты;
- недельный трекер привычек от воскресенья 05:00, блокировка прошедших/будущих дней и история недель;
- трекер выполнения задач и привычек на главной странице;
- сохраняемые журнал здоровья, план недели и четырёхэтапный вечерний разбор;
- календарь с режимами «День / Неделя / Месяц» и настоящей привязкой планов и задач к датам;
- перенос задач мышью или пальцем между датами и временем в дневном и недельном режиме, а также между днями месяца;
- отдельный сохраняемый фокус для каждой недели и выполнение задач прямо из календаря;
- связь целей с несколькими проектами и автоматический расчёт прогресса по задачам и этапам проектов;
- цели месяца, недели и сегодняшнего дня на главной странице;
- компактный мобильный трекер привычек без наложения длинных названий;
- кликабельный путь «Моя система» для мгновенного возврата на главную;
- рабочая навигация с адресами разделов через URL hash;
- AI применяет команды создания задач, целей, проектов и привычек сразу, без лишних подтверждений;
- безопасный серверный маршрут AI на официальном OpenAI SDK, Responses API и function tools;
- необязательный BYOK-режим с явным предупреждением;
- архитектура, которую можно позже подключить к Supabase.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
cp .env.example .env.local
npm run dev
```

Откройте `http://localhost:3000`. Сайт полностью работает и без ключа. Без OpenAI-ключа AI всё равно понимает простые команды вида «добавь задачи: …», а ключ включает полноценное понимание естественного языка и действия в разных разделах.

## OpenAI

Рекомендуемый вариант — серверная переменная `OPENAI_API_KEY`. Она используется только в `app/api/assistant/route.ts` и не передаётся клиенту. При необходимости модель задаётся через `OPENAI_MODEL`.

BYOK в настройках предназначен для локального тестирования. Ключ хранится в `localStorage` текущего браузера, поэтому этот режим нельзя считать таким же безопасным, как серверный.

```bash
git init
git add .
git commit -m "Launch NEXUS OS"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/nexus-os.git
git push -u origin main
```

Файл `.env.local` не коммитьте — он уже исключён через `.gitignore`.

## Vercel

1. Импортируйте GitHub-репозиторий в Vercel.
2. Framework Preset: **Next.js**.
3. В Project Settings → Environment Variables добавьте `OPENAI_API_KEY` и, при желании, `OPENAI_MODEL`.
4. Нажмите Deploy.

Если AI не нужен, переменные можно не добавлять: остальная система продолжит работать.

## Структура

```text
app/
  api/assistant/route.ts  # серверный AI-маршрут
  globals.css             # дизайн-система и адаптивность
  ios.css                 # iOS-слой, мобильная панель и интерфейс PARA
  layout.tsx              # метаданные и общий layout
  page.tsx                # интерфейс и локальная модель данных
.env.example              # пример безопасных переменных
public/                   # статические файлы
```

## Следующий шаг: Supabase

Для синхронизации между устройствами замените операции `localStorage` на репозитории данных (`tasks`, `habits`, `goals`, `projects`, `finance_entries`, `health_logs`) и подключите Supabase Auth. Интерфейс и типы предметной области можно сохранить без изменений.
