# NEXUS OS

Персональная система планирования жизни в премиальном iOS-стиле: dashboard, задачи, цепочка целей, проекты, привычки, финансы, здоровье, планирование, журнал и AI-ассистент.

## Что уже работает

- адаптивный интерфейс для телефона, планшета и компьютера;
- iOS-подобный интерфейс: системная типографика, стеклянные панели, крупные зоны нажатия, нижняя мобильная навигация и формы-шторки;
- демо-данные и полноценный локальный режим без регистрации или базы данных;
- локальное сохранение задач, привычек, финансов, планов и журналов в `localStorage`;
- простой личный вход по PIN без регистрации по email;
- автоматическая синхронизация всей системы между устройствами с локальным fallback;
- готовая SQL-миграция с Row Level Security: пользователь видит только собственную строку данных;
- «Умный центр дня» на главной: рекомендуемый порядок задач, занятость, привычки, ближайшее событие, безопасный темп расходов и статус обзора PARA;
- создание, полное редактирование и удаление задач, целей, проектов, операций и событий;
- полноценный рабочий процесс PARA: входящие, проекты, сферы, ресурсы и архив;
- быстрый разбор входящей записи в задачу или ресурс без повторного ввода;
- голосовой быстрый ввод во «Входящие» через распознавание речи браузера (если оно поддерживается устройством);
- пошаговый еженедельный обзор PARA из шести этапов: входящие, хвосты, проекты, цели, сферы и фокус следующей недели;
- редактируемые стандарты и самооценка сфер жизни;
- понятные «Контрольные точки проекта» и собственная база материалов внутри каждого проекта;
- финансовый учёт в израильских шекелях (ILS / ₪);
- отдельные счета для наличных, банка и кредитной карты, переводы и редактирование остатков;
- кредитные покупки с рассрочкой и будущим графиком платежей без повторного учёта покупки как расхода;
- месячный бюджет по категориям с живым сравнением плана и факта;
- недельная шкала расходов из наличных, банковской и кредитной карт с линией допустимого темпа;
- постоянные расходы с выбранным счётом и датой как прогноз; фактическая операция подтверждается выпиской;
- денежный календарь на любой месяц с реальными покупками, постоянными расходами, кредитными и банковскими платежами;
- журнал по 50 операций на странице, фильтр по выбранному кошельку и точная сортировка по дате;
- отдельный учёт кредитов: остаток, число платежей, ближайший платёж и ручная фиксация погашения как движения денег, а не нового расхода;

- удобный редактор финансовых категорий: добавление, переименование, удаление и изменение порядка перетаскиванием;

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
cp .env.example .env.local
npm run dev
```

Откройте `http://localhost:3000`. Сайт полностью работает и без ключа. Без OpenAI-ключа AI всё равно понимает простые команды вида «добавь задачи: …», а ключ включает полноценное понимание естественного языка и действия в разных разделах.

## OpenAI

Рекомендуемый вариант — серверная переменная `OPENAI_API_KEY`. Она используется только в серверных маршрутах ассистента и финансового импорта и не передаётся клиенту. При необходимости общая модель задаётся через `OPENAI_MODEL`, а модель распознавания финансов — через необязательную переменную `OPENAI_FINANCE_MODEL`.

BYOK в настройках предназначен для локального тестирования. Ключ хранится в `localStorage` текущего браузера, поэтому этот режим нельзя считать таким же безопасным, как серверный.

## Supabase: личный PIN и синхронизация

Email-регистрация не используется. Один личный PIN проверяется только сервером, после чего браузер получает защищённую сессию на 30 дней.

1. В Supabase откройте SQL Editor и выполните `supabase/migrations/002_nexus_pin_state.sql`.
2. В Supabase откройте Connect и скопируйте Project URL.
3. В Settings → API Keys скопируйте серверный Secret key (`sb_secret_...`). Никогда не добавляйте его в переменную с префиксом `NEXT_PUBLIC_`.
4. Добавьте в `.env.local` или в Vercel:

```bash
SUPABASE_URL=https://YOUR_PROJECT.supabase.co
SUPABASE_SECRET_KEY=sb_secret_YOUR_SERVER_KEY
NEXUS_PIN=YOUR_PERSONAL_PIN
NEXUS_SESSION_SECRET=YOUR_LONG_RANDOM_SECRET_AT_LEAST_32_CHARACTERS
```

После входа первая облачная копия создаётся автоматически. Далее изменения сохраняются примерно через секунду и проверяются на других открытых устройствах каждые 20 секунд. Таблица закрыта для браузерных ключей; читать и изменять её может только серверный маршрут сайта.

## Vercel

1. Импортируйте GitHub-репозиторий в Vercel.
2. Framework Preset: **Next.js**.
3. В Project Settings → Environment Variables добавьте `OPENAI_API_KEY` и, при желании, `OPENAI_MODEL` и `OPENAI_FINANCE_MODEL`.
4. Для личного PIN-входа добавьте `SUPABASE_URL`, `SUPABASE_SECRET_KEY`, `NEXUS_PIN` и `NEXUS_SESSION_SECRET`.
5. Нажмите Deploy.

Если AI не нужен, переменные можно не добавлять: остальная система продолжит работать.
